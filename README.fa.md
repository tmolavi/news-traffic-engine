## 📌 معرفی پروژه

در عصر هوش مصنوعی، فرمول‌های سنتی سئو (تنها چیدن کلمات کلیدی و بک‌لینک) دیگر برای سایت‌های خبری کافی نیستند. امروز بیش از ۵۰ درصد جستجوها توسط موتورهای پاسخ ترکیبی مثل **ChatGPT Search**، **Perplexity AI** و **Google AI Overviews** پاسخ داده می‌شوند و ترافیک لحظه‌ای از **Google Discover** و شبکه‌های اجتماعی تأمین می‌گردد.

پروژه **News Traffic Engine (NTE)** یک سیستم جامع و متن‌باز است که توسط **[تقی مولوی](https://molavi.pro)** (طراح فریم‌ورک‌های بین‌المللی [GEO-Scope](https://github.com/tmolavi/geo-scope) و [SAGE](https://github.com/tmolavi/sage-audit)) با همکاری راهبردی **[آژانس دیجیتال مارکتینگ اینتن](https://inten.asia)** توسعه یافته است.

## ❓ پرسش‌های متداول (FAQ) — سئو، GEO و جهش ترافیک خبری

### ۱. چگونه Google Indexing API زمان ایندکس خبر را به زیر ۱۵ دقیقه می‌رساند؟
کرولرهای معمولی گوگل ممکن است ساعت‌ها یا روزها طول بکشد تا صفحه جدید را بیابند. استفاده از API رسمی Indexing به گوگل‌بات دستور خزش با اولویت فوق‌العاده بالا صادر می‌کند؛ در نتیجه لینک ظرف ۵ تا ۱۵ دقیقه کشف و در بخش **Top Stories** و سرچ نتایج زنده قرار می‌گیرد.

### ۲. بهینه‌سازی موتورهای تولیدی (GEO) چیست و چرا برای سایت‌های خبری حیاتی است؟
بهینه‌سازی برای هوش مصنوعی (GEO) هنر مهندسی محتواست تا موتورهایی مثل ChatGPT Search و Perplexity خبر شما را به عنوان رفرنس رسمی پاسخ خود نقل کنند. طبق آمار، ۹۲ درصد استنادات هوش مصنوعی به مطالبی تعلق می‌گیرد که در لید ۴۵ کلمه‌ای پاسخ شفاف داده و پاراگراف‌های ۱۳۰ تا ۱۷۵ کلمه‌ای با نقل‌قول موثق داشته باشند.

### ۳. الزامات فنی قطعی برای حضور خبر در گوگل دیسکاور (Google Discover) چیست؟
الگوریتم دیسکاور سه شرط فنی اجباری دارد: ۱. تگ متای `<meta name="robots" content="max-image-preview:large">` در هدر صفحه. ۲. تصویر شاخص با کیفیت بالا و عرض حداقل ۱۲۰۰ پیکسل با نسبت ۱۶:۹. ۳. عملکرد عالی سرعت موبایل (LCP زیر ۱.۵ ثانیه و پایداری چیدمان CLS زیر ۰.۰۵).

### ۴. چرا بازنشر خودکار در تلگرام، ایتا، بله و توییتر ترافیک را چند برابر می‌کند؟
بیش از ۶۰ درصد درگیری مخاطبان با اخبار فوری در ۲ ساعت اول رخ می‌دهد. ارسال درجا با سناریوی خودکار n8n به کانال‌های تلگرام، ایتا و بله پیک ترافیکی فوری ایجاد کرده و سیگنال داغ بودن را به الگوریتم‌های ترند گوگل ارسال می‌کند.

### ۵. استاندارد `/llms.txt` چگونه به دیده‌شدن سایت در مدل‌های زبانی کلاد و چت‌جی‌پی‌تی کمک می‌کند؟
این فایل نسخه‌ای بسیار سبک، بدون کدهای سنگین قالب، از دسته‌های خبری و خبرهای تحلیلی به مدل‌های هوش مصنوعی ارائه می‌دهد تا در پایگاه دانش RAG با کمترین توکن و بیشترین دقت استناد ذخیره شوند.

### ۶. آیا این سیستم با وردپرس و لاراول سازگار است؟
بله؛ با ارسال یک وب‌هوک ساده از سیستم مدیریت محتوای شما به n8n یا فراخوانی CLI پایتون، کلیه مراحل ارزیابی GEO، ساخت اسکیما و ارسال به API گوگل به صورت اتوماتیک اجرا می‌شود.

## 🚀 راهنمای سریع نصب و استفاده

```bash
git clone https://github.com/tmolavi/news-traffic-engine.git
cd news-traffic-engine
pip install -e .
```

### سنجش میزان استنادپذیری خبر در هوش مصنوعی (GEO Audit):
```bash
news-traffic audit-geo \
  --headline "توافق تاریخی در اجلاس انرژی وین" \
  --lead "وین، ۲۹ اکتبر — وزرای انرژی حاضر در نشست وین روز پنجشنبه به توافقی جامع بر سر مدیریت سقف تولید نفت دست یافتند که نوسانات بازار را به میزان ۲۰ درصد مهار خواهد کرد." \
  --body "نشست پشت درهای بسته بیش از شش ساعت به طول انجامید..."
```
